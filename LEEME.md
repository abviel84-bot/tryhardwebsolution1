# TRYHARD WEB SOLUTION — Todos los archivos del proyecto

Este ZIP incluye las DOS versiones de backend (elige una, no uses las dos a la vez).

## 🔥 Estás usando Firebase → usa estos archivos:
- **`index_firebase.html`** ← este es tu sitio web. Súbelo a GitHub renombrado como `index.html`.
- **`firestore.rules`** ← pega esto en Firebase Console → Firestore Database → Reglas.
- **`INSTRUCCIONES_FIREBASE.md`** ← guía paso a paso completa.

## 🟢 Si en algún momento prefieres Supabase en vez de Firebase:
- **`index_supabase.html`** ← versión alterna del sitio, conectada a Supabase.
- **`supabase_schema.sql`** ← corres esto una sola vez en el SQL Editor de Supabase.
- **`INSTRUCCIONES_SUPABASE.md`** ← guía paso a paso completa.

---

### Recomendación
Como ya llevas camino andado con Firebase, sigue con **`index_firebase.html`** + **`INSTRUCCIONES_FIREBASE.md`**. Ignora los archivos de Supabase por ahora (los dejo por si acaso).
